# E-Commerce Data Collection and Pre-Processing

This project demonstrates an end-to-end data collection and pre-processing workflow using an e-commerce transaction dataset.
The purpose is to identify data-quality issues, clean and transform the data, and engineer useful analytical features.
A secondary 2019 U.S. population dataset is integrated to enrich the transaction data with population and geographic information.
The final workflow produces an enriched dataset that can be saved and reused in both CSV and JSON formats.

## Quick Start

```bash
python -m venv venv
```

Activate the virtual environment and install the required packages:

```bash
pip install -r requirements.txt
```

Launch Jupyter Notebook:

```bash
jupyter notebook
```

Open the project notebook and run the cells from beginning to end.
